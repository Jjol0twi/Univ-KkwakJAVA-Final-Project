# KkwakJAVA Homework Scheduler

Final team project for the university course `Introduction to Computer Programming`.

## 프로젝트 소개

`KkwakJAVA`는 대학생이 이번 주 과제를 놓치지 않도록 도와주는 Java 터미널 프로그램입니다.

사용자는 과목명, 온라인 강의 개수, 제출 과제 개수, 퀴즈 과제 개수, 제출 기한, 메모를 입력합니다. 프로그램은 입력된 과제를 표로 정리하고, 그리디 알고리즘을 사용해 지금 먼저 해야 할 과제 순서를 추천합니다.

## 실행 방법

프로젝트 폴더에서 Java 파일을 컴파일합니다.

```bash
javac *.java
```

기본 실행은 다음과 같습니다.

```bash
java KkwakJAVA
```

실행할 때 주차를 바로 넘길 수도 있습니다.

```bash
java KkwakJAVA 11주차
```

이렇게 실행하면 `이번주는 몇 주차인가요?` 질문 없이 바로 11주차 과제 입력으로 넘어갑니다.

## 주요 기능

- 이번 주차 입력 또는 실행 인자로 주차 전달
- 과목별 과제 정보 등록
- 현재 입력된 과제 목록 표 형식 출력
- 긴 과목명은 표에서 `...`으로 말줄임 처리
- 중요도 순위 수정
- 과목명 입력 위치에서 `exit` 입력 시 수정/입력 종료 메뉴 표시
- 과목명 외 입력 위치에서 `exit` 입력 시 현재 과제 등록 취소
- 남은 과제 우선순위 추천
- `계획대로 했음` 입력 시 현재 1순위 과제 완료 처리
- 모든 과제를 완료하면 다음 주차로 자동 이동
- 16주차까지 완료하면 축하 메시지 출력 후 종료

## 입력 규칙

과목명 입력 위치에서 `exit`를 입력하면 수정 또는 입력 종료 메뉴가 열립니다.

과목명 외의 입력 위치에서 `exit`를 입력하면 현재 과제 등록을 취소하고 다시 과목명 입력으로 돌아갑니다.

중요도 순위는 숫자가 낮을수록 더 중요합니다. 첫 과제는 가능한 순위가 1개뿐이므로 자동으로 1순위가 됩니다. 이미 과제가 등록된 상태에서 중요도 입력을 비워두면 마지막 순위로 자동 등록됩니다.

예를 들어 입력 가능한 중요도가 `1~3`일 때 Enter만 누르면 3순위로 등록됩니다.

## 시간 계산 기준

프로그램은 과제 수행 시간을 다음 기준으로 계산합니다.

| 항목 | 예상 시간 |
| --- | --- |
| 온라인 강의 1개 | 60분 |
| 제출 과제 1개 | 60분 |
| 퀴즈 과제 1개 | 30분 |

마감일까지 가능한 공부 시간은 다음 기준으로 계산합니다.

| 요일 | 가능한 공부 시간 |
| --- | --- |
| 평일 | 3시간 |
| 주말 | 5시간 |

## 그리디 알고리즘 적용 방식

이 프로그램은 모든 경우의 수를 계산하지 않습니다. 남은 과제 중에서 현재 기준으로 가장 먼저 해야 할 과제를 하나 선택하고, 그 다음 남은 과제 중에서 다시 가장 좋은 선택을 고릅니다.

즉, 매 단계에서 현재 가장 좋은 선택을 반복하는 그리디 방식입니다.

우선순위 비교 기준은 다음 순서입니다.

1. 마감 초과 위험이 높은 과제
2. 중요도 순위가 높은 과제
3. 긴급도가 높은 과제
4. 필요한 시간이 많은 과제
5. 제출 과제가 많은 과제

이 프로그램은 동적 계획법처럼 `dp` 배열을 만들거나 모든 조합을 비교하지 않습니다. 전역 최적해를 보장하는 프로그램이라기보다는, 학생이 지금 무엇부터 해야 할지 빠르게 판단하도록 돕는 우선순위 추천 프로그램입니다.

## 클래스 구조

| 클래스 | 역할 |
| --- | --- |
| `KkwakJAVA` | 프로그램 시작점 |
| `Assignment` | 과목 하나의 과제 정보 저장 |
| `AssignmentList` | 과제 배열과 중요도 순위 관리 |
| `AssignmentInputHandler` | 사용자 입력을 과제 객체로 변환 |
| `InputReader` | Scanner 입력 처리 |
| `AssignmentView` | 표, 메뉴, 결과 출력 |
| `AssignmentService` | 전체 프로그램 흐름 제어 |
| `AssignmentProgressManager` | 완료 처리 관리 |
| `DeadlineCalculator` | 제출 기한과 남은 기간 계산 |
| `TextNumberParser` | 문자열에서 숫자 추출 |
| `StudyTimeCalculator` | 필요한 시간과 가능한 시간 계산 |
| `GreedyAssignmentScheduler` | 그리디 기준으로 과제 순서 계산 |
| `GreedyScheduleItem` | 그리디 결과 출력 항목 |

## 실행 흐름

1. 프로그램 시작
2. 이번 주차 입력 또는 실행 인자로 주차 전달
3. 과목명과 과제 정보 반복 입력
4. 현재 입력된 과제 목록 출력
5. 입력 종료 후 그리디 우선순위 출력
6. 과제 완료 처리
7. 모든 과제가 완료되면 다음 주차로 자동 이동
8. 16주차 완료 후에는 축하 메시지를 출력하고 프로그램 종료

## 출력 예시

현재 입력된 과제 목록은 표 형태로 출력됩니다.

```text
[현재 입력된 과제 목록]
순위  과목명              강의    제출    퀴즈  남은기한  상태      메모
--------------------------------------------------------------------------------------
   1  커리어디자인         2개     0개     1개       5일  진행중    소통 공감 화합을 이끌어가는 힘
   2  문제해결을 위...     3개     0개     1개       5일  진행중    다음주 시험
```

입력을 종료하면 남은 과제 우선순위를 보여줍니다.

```text
[11주차 남은 과제 먼저 해야 할 순서]
1순위. 커리어디자인
   제출 기한: 5/31, 남은 기간: 5일, 예상 필요 시간: 2시간 30분
   온라인 강의: 2개, 제출 과제: 0개, 퀴즈 과제: 1개
   마감 초과 위험: 없음
   메모: 소통 공감 화합을 이끌어가는 힘
```

16주차까지 모든 과제를 완료하면 다음 메시지가 출력됩니다.

```text
        *       .        *        .       *
   .        *        .        *        .
       _/\_                         _/\_
    <(o )___   한 학기 과제 완료   ___( o)>
     ( ._> /      수고했습니다!      \ <_. )
      `---'                         `---'

KkwakJAVA가 과제 관리를 마무리합니다.
```

## 발표 요약

이 프로그램은 대학생의 과제 관리를 돕기 위한 터미널 기반 Java 프로그램입니다. 입력된 과제를 단순히 나열하는 것이 아니라, 마감 위험과 중요도, 작업량을 기준으로 지금 먼저 해야 할 과제를 추천합니다.

전체 경우의 수를 모두 계산하지 않고 매 단계에서 가장 우선순위가 높은 과제를 선택하므로 그리디 알고리즘 방식으로 볼 수 있습니다. 클래스는 입력, 출력, 데이터 저장, 시간 계산, 그리디 계산, 완료 처리, 전체 흐름 제어 역할로 나누었습니다.
